# Arquitetura do projeto

## Objetivo

Plataforma de estudos aplicados de Engenharia de Dados,
Analytics e Ciência de Dados.

Fontes de dados

## Componentes

| Componente | Responsabilidade |
|---|---|
| Ingestão | Carregamento de dados |
| Qualidade | Validação e consistência |
| Transformação | Limpeza e preparação |
| Persistência | Armazenamento dos resultados |
| Analytics | Indicadores e análises |
| Machine Learning | Modelos preditivos |

## Dados

Os dados utilizados nos estudos são fictícios
