1Instalar e conferir

Onde: python.org (Python 3.11 ou mais novo; na instalação marque "Add Python to PATH"), code.visualstudio.com (VS Code) e git-scm.com (Git). Depois abra o PowerShell (menu Iniciar → digite "PowerShell") e confira:

python --version        # ou: py --version   (Linux/Mac: python3 --version)
git --version
code --version
Deu número de versão nos três? Então está pronto. Se aparecer "não é reconhecido", veja a tabela de problemas no final.

Extensões do VS Code: clique no ícone de quadradinhos à esquerda (Ctrl+Shift+X), procure e instale Python e Jupyter (ambas da Microsoft).

2Criar a pasta do projeto e abrir no VS Code

Regra de ouro Crie o projeto fora da pasta do GATE4. Assim o sistema em produção fica intocado.
mkdir C:\Projetos\gate4-data-platform
cd C:\Projetos\gate4-data-platform
code .                  # abre o VS Code nesta pasta

Sem o comando code: abra o VS Code → File → Open Folder… → escolha a pasta. Quando perguntar "Do you trust the authors?", clique em Yes.

3Terminal integrado, ambiente virtual e interpretador

Abrir o terminal dentro do VS Code: menu Terminal → New Terminal ou Ctrl+`. Ele já abre na pasta do projeto.

python -m venv .venv                  # cria a caixa isolada (uma vez só)
.venv\Scripts\Activate.ps1            # ativa (Linux/Mac: source .venv/bin/activate)

Quando ativar, aparece (.venv) no começo da linha do terminal.

Erro comum no Windows "a execução de scripts foi desabilitada": rode uma vez Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned e tente ativar de novo.

Dizer ao VS Code qual Python usar: Ctrl+Shift+P → digite Python: Select Interpreter → escolha o que termina em .venv. (Se ele pedir, aceite a sugestão de usar o ambiente da pasta.) Depois disso, todo terminal novo ativa o venv sozinho.

4Instalar só o que precisa agora

python -m pip install --upgrade pip
pip install pandas numpy pyarrow matplotlib pytest ipykernel
pip freeze > requirements.txt       # registra as versões instaladas
Por quê só isso O projeto introduz tecnologia aos poucos: SQLAlchemy/psycopg2 (ler Postgres), Docker, dbt e Airflow só entram quando houver necessidade.

5Estrutura de pastas, pyproject e .gitignore

mkdir src\gate4, tests, notebooks, data\raw, data\processed
ni src\gate4\__init__.py              # arquivo vazio (Linux/Mac: touch; mkdir -p)

Crie (File → New File) o arquivo pyproject.toml na raiz:

[build-system]
requires = ["setuptools>=68"]
build-backend = "setuptools.build_meta"

[project]
name = "gate4"
version = "0.1.0"
requires-python = ">=3.10"

[tool.setuptools.packages.find]
where = ["src"]

[tool.pytest.ini_options]
pythonpath = ["src"]
pip install -e .                      # deixa "import gate4" funcionar em qualquer lugar do projeto

Crie o .gitignore (raiz) com:

.venv/
__pycache__/
.ipynb_checkpoints/
data/
.env
*.parquet
Importante data/ e .env nunca vão para o GitHub: dados e senhas ficam só na sua máquina.

6Git e GitHub

git push -u origin main
Hábito Faça um commit a cada tarefa pequena. Mensagens curtas e claras, como "Adiciona gerador de empresas". Recrutadores olham o histórico.

7Executar código: três jeitos (e quando usar cada um)

Primeiro um teste de fumaça para confirmar que tudo funciona. Crie src\gate4\smoke.py:

import numpy as np, pandas as pd

rng = np.random.default_rng(42)
df = pd.DataFrame({"id": range(1, 6), "valor": rng.integers(100, 500, 5)})
print(df)
JeitoComoUse para
A. Botão ▶Abra o arquivo e clique em ▶ Run Python File (canto superior direito).Rodar rápido enquanto escreve.
B. Terminalpython -m gate4.smokeO jeito do projeto: reproduzível por qualquer pessoa.
C. NotebookFile → New File → Jupyter Notebook; salve em notebooks\; escolha o kernel .venv (canto superior direito); rode a célula com Shift+Enter.Explorar dados e testar ideias.
Viu a tabela com 5 linhas no terminal? Seu ambiente está funcionando.

10Dados reais: só depois, e em cópia

Comece pelos dados sintéticos (Guia 18, módulo M0), que não tocam em nada. Quando for usar dados reais, trabalhe numa cópia local, nunca direto na produção:

pg_dump -h SEU_HOST -U SEU_USUARIO -d SEU_BANCO -Fc -f gate4.dump   # só lê o banco
createdb gate4_copia
pg_restore -d gate4_copia gate4.dump

Anonimize nome e telefone apenas na cópia, e nunca publique esses dados. Faça isso somente depois de analisarmos e você decidir.

🛠️ Problemas comuns

Mensagem/sintomaO que fazer
'python' não é reconhecidoReinstale marcando "Add to PATH" ou use py no lugar de python; feche e reabra o terminal.
ModuleNotFoundError: pandasO venv não está ativo ou o VS Code usa outro interpretador: ative .venv e refaça "Select Interpreter".
No module named gate4Rode pip install -e . na raiz, com o venv ativo.
Notebook sem kernelCanto superior direito → "Select Kernel" → Python Environments → .venv.
Acentos quebrados em CSVUse encoding="utf-8" ao ler e gravar.
git push pede loginEntre pelo navegador (Git Credential Manager) ou use um token do GitHub como senha.
